# Prompt Pack — Kazumi

Paste-ready Higgsfield **GPT Image 2** prompts. Styles: **GTA VI** and **Cyberpunk 2077**.
All **SFW / glam-but-clothed** (see `creators/kazumi/profile.md`).

**How to run each prompt**
1. Higgsfield → GPT Image 2 → aspect ratio **9:16**, resolution 2k, quality high.
2. Attach a clean reference photo of Kazumi (image-to-image) for likeness. For a consistent
   set, train a **Soul ID** on her `refs/` and use it.
3. Generate 2–3 variants, keep the best.

**Tags:** `[style · scene · look]`. **look** = `full-render` (all in-engine) or
`cgi-in-scene` (stylized character on a photoreal backdrop). Full style detail lives in
`skills/gta6-style/` and `skills/cyberpunk-2077-style/`.
