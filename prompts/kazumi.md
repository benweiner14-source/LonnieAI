# Prompt Pack — Kazumi

Paste-ready Higgsfield **GPT Image 2** prompts. Styles: **GTA VI** and **Cyberpunk 2077**.
All **SFW / glam-but-clothed** (see `creators/kazumi/profile.md`).

**Her real look (from `refs/`, woven into the prompts below):** a Filipina-American woman with
an hourglass figure, **long wavy balayage hair (blonde with darker roots)** worn down or in a
**high ponytail**, **full glam makeup** (bold winged liner, long lashes, arched brows, glossy
nude-pink lips), and **gold hoops + a green jade teardrop pendant**. Confident, sultry, camera-aware.

**One look: FULL CGI RENDER.** Every prompt renders the **entire frame — character AND
environment — in the game engine** (an in-game shot). We dropped the "CGI character composited
into a photoreal scene" look — GPT Image 2 couldn't hold it.

**⚠️ Brand safety — no real logos/trademarks.** Earlier prompts named real properties (e.g.
"GTA VI", "Cyberpunk 2077", real engine/studio names) and the model started rendering **real
game logos, studio branding, and in-universe trademarked names** into outputs — not usable for
a commercial page. All prompts below are genericized to describe the *aesthetic* (neon open-world
crime-saga look; neon-noir cyberpunk look) without naming a real game, studio, or engine, using
invented place names instead of the real trademarked ones, and each ends with a **no real
logos/trademarks** clause. If you write new prompts, keep this rule: describe the *look*, never
the *brand*.

**How to run each prompt**
1. Higgsfield → **Nano Banana** (current best quality/consistency per testing) or GPT Image 2 →
   aspect ratio **9:16**, resolution 2k, quality high.
2. **Bind her identity:** attach 1–2 clean reference photos from `refs/` directly (Nano Banana
   handles this well). **Soul 2.0 tested worse than Nano Banana / GPT Image 2** — skip training a
   Soul ID for now; use direct reference photos instead.
3. Generate 2–3 variants, keep the best. Keep everything SFW.

**Fidelity note:** her looks are *meant* to read as a **stylized game character**. If a result
looks like a plain photo, push the style DNA harder ("in-game render, stylized game-engine
character, not photoreal") — see `docs/higgsfield-cgi-playbook.md`.

**Tags:** `[style · scene]`. Full style detail in `skills/gta6-style/` and
`skills/cyberpunk-2077-style/`.

> v3 — all full CGI render; tuned to refs in `creators/kazumi/refs/`. Cyberpunk prompts keep her
> balayage waves but add optional neon streaks for the cosplay; swap back to natural if preferred.
