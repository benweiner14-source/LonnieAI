# Zion — Soul ID training set (20 images)

Curated from a 45-post Instagram scrape (@zionclark): clear face shots from varied
angles + clean physique/action frames. Excluded promo graphics with text overlays,
group shots, distant frames, and artistic edits (bad for identity training).

## Create the Soul ID in Higgsfield
1. Upload all `soul_*.jpg` here as the character's training images.
2. Name it e.g. `zion` and create the Soul ID (Soul 2 tier for best fidelity).
3. Generate with the Soul ID + a prompt from `../../../prompts/zion-clark.md`
   (text-to-image, not img2img) so it renders fresh in the requested style while
   keeping his face — the reliable path to a CGI character (see
   `../../../docs/forcing-the-cgi-look.md`).

Tip: for the CGI look, still attach an NBA 2K style frame from
`reference-material/2k-screenshots/` and keep the CGI-enforcement block in the prompt.
