# Reference stills

Curated reference photos of the creator go here (from the Apify Instagram scrape or
provided directly). Used to:
1. Attach in Higgsfield GPT Image 2 (image-to-image) for likeness.
2. Train a Higgsfield **Soul ID** for consistent identity across a set.
3. Guide prompt wording (exact hair, wardrobe, physique, signature poses).

Prefer 4–6 clean, well-lit, varied-angle shots. Large image files are gitignored by default.
